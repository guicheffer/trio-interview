# Phase 2: Bug Fixing

**Suggested time**: ~15 minutes

---

## Objective

Run the tests. Some fail. Work out why, fix the code (not the tests), and explain what you found.

```bash
cd codebase && npm test
```

---

## What to Do

1. Run the tests and read the failures before touching anything.
2. For each failure, decide whether the test or the code is wrong, and say why.
3. Fix the code, rerun, and check nothing else broke.
4. Try the app in the browser too: does what you fixed behave in the page as well?

---

## Success Criteria

- Reads the failing output instead of guessing
- Finds the cause, not just a change that turns the test green
- Keeps the fix small and explains it
- Checks the AI's suggestion against the code before accepting it
