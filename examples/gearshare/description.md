# GearShare

A 60-minute collaborative coding exercise in an AI-assisted development environment.

## Format

- **Structure**: progressive phases, shared by your interviewer as the session goes
- **Stack**: React, Express.js, SQLite (built into Node)
- **AI**: Use the integrated AI assistant throughout, it's part of the evaluation

## Quick Start

```bash
cd codebase && npm install && npm run db:migrate && npm run dev
```

**Demo users** (pick one on the login page): ana@example.test · ben@example.test · chloe@example.test · dev@example.test

## What it is

GearShare lets neighbours lend each other tools, camping gear and electronics. Someone lists an item, someone else asks to borrow it for some dates, and the owner approves, hands it over and marks it returned.

## Phase Overview

| Phase | File | Suggested Time |
|-------|------|---------------|
| 1, Code Comprehension | `phases/phase-1-comprehension.md` | ~5 min |

Your interviewer shares the next phase when you are ready.

> **Note**: Timeframes are flexible guidelines, not hard limits.

## How to Use the AI Assistant

- Ask it to explain code, review changes, suggest improvements
- It can read and modify files directly
- Think aloud, describe your approach before coding
