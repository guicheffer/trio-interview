# Fibonacci

A 20 minute Node exercise with one file (in `examples/`, add it with `make config` or `make new-exercise FROM=fibonacci`). Use it to try the tool, to demo it, or to check your setup before an interview. It is not an assessment exercise.

## Running it

- Nothing hidden and no app to start. The candidate implements `fibonacci.js` with the AI assistant and runs it with `node fibonacci.js`.
- Ten tests in `fibonacci.test.js` (read only for the candidate) check both functions: empty, 0, 1, 5, 10, a negative input and a fraction, and the limit of `fibonacciUpTo`. **Run tests** runs them, and the starter fails all ten.
- Good for a dry run of the whole flow: start, share the link, watch the candidate's workspace, export.
