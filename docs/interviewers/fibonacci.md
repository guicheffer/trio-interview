# Fibonacci

A 20 minute Node exercise with one file. Use it to try the tool, to demo it, or to check your setup before an interview. It is not an assessment exercise.

## Running it

- Nothing hidden and no app to start. The candidate implements `fibonacci.js` with the AI assistant and runs it with `node fibonacci.js`.
- Good for a dry run of the whole flow: start, share the link, watch the candidate's workspace, export.

## Known gaps

- The stub in `fibonacci.js` describes `fibonacci(n)` as returning the nth number, while `description.md` asks for an array of the first n numbers. The assistant follows the stub. Mention this to the candidate or pick one in the exercise.
